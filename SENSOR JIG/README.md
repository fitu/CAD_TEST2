# מתקן מסילה לחיישן M10

המתקן נצמד בלחץ לשני קירות קשיחים במפתח של **490–510 מ״מ**, עם מידה נומינלית של **500 מ״מ**. מסילה בחתך 40×40 מ״מ בנויה משני מקטעים באורך 234 ו־210 מ״מ, המחוברים במחבר פנימי מרובע. אורך החלק השמאלי, כולל אוגן הקיר, הוא 248 מ״מ. עגלה מרובעת עוטפת את המסילה ומחליקה לאורכה על פני **368 מ״מ** בין מעצורי הקצה. החתך המרובע מונע סיבוב בזמן התנועה. העגלה כוללת מוביל אנכי באורך 60 מ״מ ובו מחליק עם מהלך מוגבל של **80 מ״מ**. אפשר לנעול כל ציר בנפרד.

ציר החיישן אנכי ופאת החישה פונה מטה. המחזיק בולט קדימה מהמוביל כדי להשאיר את האזור שמתחת לחיישן פתוח. בזמן ההרכבה מקמים את פאת החישה מעט מתחת לפאה התחתונה של המחזיק, ובודקים גם את מרווח הגילוי שהיצרן דורש מסביב לחיישן.

## קבצים והדפסה

- [print](print) כולל את חלקי ההדפסה ב־STL. יחידות המידה הן מ״מ.
- [sensor_jig.step](sensor_jig.step) הוא מודל ההרכבה עם ייצוגי החומרה והחיישן. [step](step) כולל מודלי STEP של החלקים הבודדים.
- [assembly_preview.png](assembly_preview.png) מציג את ההרכבה ואת העגלה עם מחזיק החיישן.
- [generate.py](generate.py) הוא המקור הפרמטרי ב־CadQuery. מתיקיית השורש של הפרויקט, הריצו `.venv/bin/python 'SENSOR JIG/generate.py'` עם התלויות המופיעות ב־`requirements.txt`.
- [validation.json](validation.json) מכיל את תוצאות הבדיקות הגאומטריות של המודלים.

החלקים מיועדים למעטפת בנייה שמרנית של **300 × 320 × 325 מ״מ** ב־Bambu H2D. ב־STL מקטעי המסילה עומדים עם שקעי המחבר כלפי מעלה. הדפיסו אותם בנפרד עם שוליים ליציבות. לחלקים הקשיחים התחילו ב־PETG או ASA, בגובה שכבה של 0.2 מ״מ וכחמש דפנות. הדפיסו פעמיים את `wall_pad_tpu.stl` ב־TPU, או חתכו שתי רפידות גומי בעובי 2 מ״מ. בדקו ב־Bambu Studio את התמיכות, במיוחד בפתח המוביל האנכי של העגלה ובקדחים הרוחביים. הסירו שאריות תמיכה לפני בדיקת ההחלקה. מרווח התכן הוא 0.25 מ״מ לכל צד בשני הצירים ו־0.30 מ״מ לכל צד במחבר הפנימי. שמרו על קנה מידה 100%.

| קובץ STL | חלק | מידות בהדפסה X×Y×Z (מ״מ) |
| --- | --- | --- |
| `rail_left` | מסילה עם אוגן קבוע | `72×58×248` |
| `rail_right` | מסילה עם שקע לבורג הלחץ | `44×40×210` |
| `rail_splice` | מחבר פנימי | `110×24×24` |
| `x_carriage` | עגלה אופקית ומוביל אנכי | `60×89×50` |
| `z_sensor_slide` | מחליק אנכי ומחזיק חיישן | `153×55×26` |
| `z_top_stop` | מעצור עליון למחליק | `32×28×6` |
| `pressure_shoe` | נעל לחץ | `72×58×8` |
| `wall_pad_tpu` | רפידת קיר, שתי יחידות | `58×72×2` |

## חומרה נדרשת

| שימוש | חומרה |
| --- | --- |
| חיבור פנימי של שני חצאי המסילה | 4 ברגי אלן ראש גלילי M5×30 ו־4 אומי M5 |
| הצמדה לקירות | בורג M12×65 מושחל לכל אורכו, אום M12 ברוחב 19 מ״מ בין פאות, אום נמוך M12 בעובי 6 מ״מ, שתי דסקיות M12 בקוטר חיצוני 24 מ״מ ובעובי 2.5 מ״מ, ושתי רפידות בעובי 2 מ״מ |
| עצירת המחליק האנכי | בורג M4×12 ותותב הברגה M4 להתקנה בחום |
| החזקת החיישן | אום M10 ברוחב 17 מ״מ בין פאות ובפסיעה שתואמת לחיישן, בורג קיבוע M4×14 עם קצה ניילון ותותב הברגה M4 להתקנה בחום |
| נעילת הצירים | 2 ברגי M5×10 עם קצה ניילון ו־2 תותבי הברגה M5 להתקנה בחום |

קדח החיישן הוא בקוטר 10.4 מ״מ. ההברגה נתפסת באום המתכתי שבכיס העליון. מדדו את פסיעת החיישן לפני רכישת האום. M10×1 היא אפשרות נפוצה. בדגם הייחוס כ־18 מ״מ מתבריג החיישן מגיעים מפאת החישה דרך האום. תותבי M4 נכנסים לקדח 5.6 מ״מ בעומק 6 מ״מ לצד החיישן ו־8 מ״מ בקצה המחליק. תותבי M5 נכנסים לקדח 7.1 מ״מ בעומק 5 מ״מ. בדקו התאמה למידות היצרן והקפידו שהתותבים יישארו שקועים.

## הרכבה וכיוון

1. מדדו את המרחק בין הקירות בגובה ההתקנה. הדביקו רפידה אחת על האוגן בצד הקבוע ורפידה אחת על הגב השטוח של נעל הלחץ.
2. השחילו את העגלה על החצי השמאלי מקצה החיבור שבמרכז. הכניסו את המחבר המרובע, הצמידו אליו את החצי הימני והדקו את ארבעת ברגי החיבור. ודאו שהראשים והאומים שקועים ושאין מדרגה במעבר בין החצאים. מעצורי הקצה מגבילים את תנועת העגלה.
3. הכניסו את אום ה־M12 לכיס הנגיש מהצד. הרכיבו את בורג ההצמדה עם האום הנמוך ודסקית אחת מול המסילה. שימו את הדסקית השנייה בשקע שבנעל הלחץ, כך שראש הבורג ילחץ על הדסקית. תמכו בנעל ובמסילה בזמן ההצבה. סובבו את ראש הבורג בעדינות עד שהרפידות נצמדות לשני הקירות, ואז הדקו את האום הנמוך נגד הדסקית שבצד המסילה.
4. התקינו את תותבי ההברגה. השחילו את המחליק למוביל מלמטה והבריגו את כיפת העצירה לראש המחליק. ודאו שתנועתו חופשית לאורך 80 מ״מ ושכיפת העצירה נשארת מחוברת בקצה המהלך התחתון.
5. הושיבו את האום בכיס העליון והשחילו דרכו את החיישן. כוונו את גובה החיישן והשאירו את פני החישה מתחת למחזיק. הדקו בעדינות את בורג הקיבוע הרוחבי על גוף החיישן. לקביעת המיקום, הזיזו את שני הצירים והדקו את בורג הנעילה של כל ציר.

בחנו את אב־הטיפוס עם עומס דמה קל לפני התקנת החיישן. בדקו היצמדות לקירות, מעבר חלק בתפר, חופש בכבל, מרווח חישה בכל המהלך והתרופפות לאחר שהמתקן נשאר תחת לחץ. בבדיקת ה־CAD הושאר גליל פנוי בקוטר 20 מ״מ ולעומק 100 מ״מ ישירות מתחת לפאת החישה. התאימו את המרווח לדרישות החיישן ולסביבת ההתקנה בפועל. כושר הנשיאה ואחיזת הרפידות תלויים בחומר, בהדפסה ובמשטחי הקיר ודורשים בדיקה פיזית.
